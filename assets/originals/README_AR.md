# صقر الوادي — حزمة الاسترجاع الجزئي

**الحالة:** بيانات وصفية ونص واجهة فقط. **ليست ملفات مصدر اللعبة الأصلية**، ولا تحتوي كود HTML/CSS/JavaScript/Swift أو ملفات Xcode أو نماذج/أصول ثلاثية الأبعاد.

## ما أمكن التحقق منه

- الاسم: صقر الوادي.
- الملف النصي في مكتبة المستخدم: `صقر الوادي نموذج لعبة طيران.txt`.
- النص المحفوظ في المكتبة أعيد وضعه داخل `recovered_ui_text.txt` دون إضافة مصدر برمجي مزعوم.
- الرابط المنشور: https://saqr-alwadi-flight-game.bdran9boot.chatgpt.site
- رقم نسخة مصدر الموقع وفق بيانات المكتبة: 6. هذا رقم وصفي وليس ملف نسخة قابلًا للتنزيل.
- معرّف الجلسة الذي قدمه المستخدم: `01a145c4-a494-707a-81e3-d5ec5b760053`.

## ما تعذر استرجاعه

لم تسمح الأدوات المتاحة بتنزيل شيفرة مشروع الموقع أو ملفات جلسة Xcode/Codex مباشرة بالمعرّف. كما أن أداة استرجاع ملفات المكتبة لم تتمكن من إحضار ملف الموقع الأصلي لأن النسخة المحفوظة Site projection. تعذر الوصول إلى الموقع المنشور من أداة الويب في هذه الجلسة.

## لاستكمال استعادة الشيفرة الأصلية

افتح جلسة Codex/Xcode المرتبطة بالمعرّف المذكور، واطلب منها تصدير مجلد المشروع كاملًا كملف ZIP، مع الملفات المصدرية وأي أصول وخامات وملفات تشغيل/بناء. أو أرفق حزمة المشروع الأصلية في هذه المحادثة.
