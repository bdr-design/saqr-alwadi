# بيوت فيلمورا — 7 أنواع، سليمة ومدمّرة

تحتوي الحزمة على 14 صورة PNG بمقاس 1024×1024 بكسل:
`h1.png` و`h1_ruin.png` إلى `h7.png` و`h7_ruin.png`.

الخلفية بنفسجي ثابت RGB(255, 0, 255)، والمنظور عمودي من فوق. اتجاه الإضاءة من أعلى اليسار. الصور بلا أشخاص أو شعارات أو نصوص أو مبانٍ دينية.

تم تطبيق تصغير موحّد وإزاحة واحدة لكل زوج، بلا مطّ أفقي أو رأسي، مع بقاء هامش للركام. يبلغ أطول ضلع للبيت السليم قرابة 70% من مساحة الصورة. لا تقصّ صورة الدمار بصورة مستقلة عن السليم إذا كان القص سيغيّر نقطة الارتكاز.

`manifest.json` يتضمن المقاسات المترية الاسمية، وحدود المحتوى بالبكسل لكل صورة ونقطة الارتكاز. إحداثيات الحدود بصيغة [يسار، أعلى، يمين غير مشمول، أسفل غير مشمول]. المقاسات المترية مواصفات التوليد؛ نسب الرسم الناتج تقريبية، وليست مخططات هندسية مقاسة.

`PROMPTS.md` يتضمن مواصفات التوليد والتصحيح والدمار.

تمت مراجعة الصور بصريًا وفحص المقاس والصيغة واللون والأسماء. لم يُختبر تركيبها داخل محرك اللعبة، ولم تُعدَّل ملفات اللعبة.
