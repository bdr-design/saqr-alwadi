# صقر الوادي — Saqr Al-Wadi

محاكاة مقعد المدفعي في مروحية أباتشي AH-64 تدور فوق وادٍ جبلي: القمرة بشاشاتها الحيّة، وكاميرا الاستهداف (بصري وحراري) على شاشة TEDAC. الخريطة صورة واقعية ثابتة، وفوقها رتل مركبات يسير على الطريق بفيزياء حقيقية، ومواقع وأفراد، وضربات بالهيلفاير والصواريخ والمدفع، ونظام ليلي.

## التشغيل

```bash
python3 tools/build.py          # يبني index.html و build/artifact.html من المصدر
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

اللعبة صفحة واحدة تعتمد على three.js r128 من cdnjs، وتُحمّل البلاطات والصور من `tiles/` و`sprites/`.

## هيكل المستودع

| المسار | المحتوى |
|---|---|
| `src/game.src.html` | مصدر اللعبة كاملًا. فيه العنصر `__ROAD__` الذي يُستبدل بنقاط الطريق عند البناء |
| `data/road.json` | خط منتصف الطريق المستخرج من الخريطة (526 نقطة كل 1.7 م، طوله نحو 894 م، والمقياس 0.85 م/بكسل) |
| `tiles/{0..3}/x_y.jpg` | هرم بلاطات الخريطة: بلاطات 1024 بكسل، من ×1 إلى ×8 |
| `tiles/far/` | المحيط البعيد 6 × 6 كم حول الوادي (16 بلاطة)، وصورة الخريطة التكتيكية `tsd.jpg` |
| `sprites/` | صور المركبات السبع من الأعلى، ونسخها المحترقة وظلالها، وصورة المقاتل، وصور المؤثرات، وصورتا القمرة `cockpit_day/night.webp` |
| `tools/build.py` | بناء الصفحة |
| `tools/make_sprites.py` و`tools/extract_road.py` | إعادة بناء الصور والطريق من الأصول |
| `tools/make_tiles.py` | توليد البلاطات من الخريطة المكبّرة |
| `tools/make_farfield.py` | بناء المحيط البعيد من عينات التضاريس، مع إبقاء الوادي الأصلي كما هو |
| `tools/make_cockpit.py` | قص الزجاج والشاشات من صورتي القمرة |
| `tools/build_onnx.py` و`tools/upscale.py` | تحويل Real-ESRGAN إلى ONNX بدون torch، ثم التكبير المقسّم |
| `tests/*.cjs` | اختبارات Playwright: لقطات، والدوران، والوضع العمودي، وتحريك الكاميرا، والمركبات، والحراري، والقمرة |
| `assets/originals/` | الصور الأصلية التي زوّدنا بها صاحب المشروع، وملفات الاسترجاع |

## التحكم

- **سحب بإصبع واحد:** تحريك الكاميرا، مع زخم.
- **قرصة أو أزرار مجال الرؤية:** التكبير من ×1 إلى ×12.
- **نقر على هدف، أو زرّا الهدف السابق والتالي:** قفل التتبع.
- **تسليح ARM، ثم إطلاق FIRE:** الإطلاق بالهيلفاير أو صواريخ هايدرا أو المدفع 30 ملم.
- **القمرة / شاشة الاستهداف:** الرجوع لمنظر القمرة والدخول للشاشة (أو النقر على الشاشة الوسطى).
- **داخل القمرة:** سحب للنظر حولها، وقرصة للانحناء نحو الشاشات، والنقر على أزرار الشاشتين الجانبيتين لتبديل الصفحات واختيار السلاح.
- **الاستهداف من القمرة:** لمس الهدف على شاشة TEDAC، وسحب عليها لتحريك المستشعر، ونقرتان للانحناء نحوها. أزرار إطارها للتكبير والسلاح والتسليح والتثبيت، والمقبض الأيمن للإطلاق والأيسر للتثبيت.
- **نهاري / ليلي:** تبديل الوضع.
- **أزرار أخرى:** الصوت، وتجميد المشهد، وحفظ صورة، وإعادة التوسيط.

## الاختبارات

```bash
npm i playwright
curl -o tests/three.min.js https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
node tests/game.cjs
```

تُحفظ اللقطات في `tests/out/`. لفتح واجهة التصحيح `window.__saqr` افتح الصفحة مع `#debug`.
