# صقر الوادي — Saqr Al-Wadi

محاكاة شاشة مستشعر استهداف (Targeting Pod) لطائرة تدور فوق وادٍ جبلي. الخريطة صورة واقعية ثابتة، وفوقها رتل مركبات يسير على الطريق بفيزياء حقيقية، ومواقع وأفراد، وضربات بالصاروخ والمدفع، ونظام ليلي.

## التشغيل

```bash
python3 tools/build.py          # يبني index.html و build/artifact.html من المصدر
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

اللعبة صفحة واحدة تعتمد على three.js r128 من cdnjs، وتُحمّل البلاطات والصور من `tiles/` و`sprites/`.

## هيكل المستودع

| المسار | المحتوى |
|---|---|
| `src/game.src.html` | مصدر اللعبة كاملًا. فيه العنصر `__ROAD__` الذي يُستبدل بنقاط الطريق عند البناء |
| `data/road.json` | خط منتصف الطريق المستخرج من الخريطة (526 نقطة كل 1.7 م، طوله نحو 894 م، والمقياس 0.85 م/بكسل) |
| `tiles/{0..3}/x_y.jpg` | هرم بلاطات الخريطة: بلاطات 1024 بكسل، من ×1 إلى ×8 |
| `sprites/` | صور المركبات السبع من الأعلى، ونسخها المحترقة وظلالها، وصورة المقاتل، وصور المؤثرات |
| `tools/build.py` | بناء الصفحة |
| `tools/make_sprites.py` و`tools/extract_road.py` | إعادة بناء الصور والطريق من الأصول |
| `tools/make_tiles.py` | توليد البلاطات من الخريطة المكبّرة |
| `tools/build_onnx.py` و`tools/upscale.py` | تحويل Real-ESRGAN إلى ONNX بدون torch، ثم التكبير المقسّم |
| `tests/*.cjs` | اختبارات Playwright: لقطات، والدوران، والوضع العمودي، وتحريك الكاميرا، والمركبات |
| `assets/originals/` | الصور الأصلية التي زوّدنا بها صاحب المشروع، وملفات الاسترجاع |

## التحكم

- **سحب بإصبع واحد:** تحريك الكاميرا، مع زخم.
- **قرصة أو أزرار مجال الرؤية:** التكبير من ×1 إلى ×12.
- **نقر على هدف، أو زرّا الهدف السابق والتالي:** قفل التتبع.
- **تسليح ARM، ثم إطلاق FIRE:** الإطلاق بالصاروخ أو القنبلة أو المدفع.
- **نهاري / ليلي:** تبديل الوضع.
- **أزرار أخرى:** الصوت، وتجميد المشهد، وحفظ صورة، وإعادة التوسيط.

## الاختبارات

```bash
npm i playwright
curl -o tests/three.min.js https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
node tests/game.cjs
```

تُحفظ اللقطات في `tests/out/`. لفتح واجهة التصحيح `window.__saqr` افتح الصفحة مع `#debug`.
